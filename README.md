This is a CLI version of a modified blackjack card game using Python. The game has the following rules:
 1. Has an unlimited deck size.
 2. Does not include any jokers in the deck.
 3. Face cards (Jack, Queen and King) are all worth 10 points. Ace can either be worth 11 or 1 points depending on total score.
 4. Does not include any card suits. (i.e. Club, Spades, etc.)
 5. Cards have an equal probability of being drawin.
 6. Cards drawn do not disappear from the deck.
 7. Computer deals cards for you.

This program was made in order to demonstrate my understanding of some key concepts in procedural programming, namely: 
  1. Control flow. 
  2. Looping and conditional statements.
  3. Creating functions requiring inputs and returning outputs.

In order to run this program, download the files and run it in your preferred Python IDE.
